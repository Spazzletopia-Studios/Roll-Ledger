# Roll Ledger

Free public roll history for Foundry V13 and V14, with PF2e and D&D 5e
action filters and native light/dark themes. No other module is required.
Open it through Settings → Configure Settings → Roll Ledger → Open Roll Ledger.
You can also open it from the SpazzMods scene controls.

The report saves public evaluated rolls, grouped by the roll's calendar date.
It shows roll events and individual dice separately. Click a player or die to
filter the report; click an action for its records. Click pins a panel, and
Escape closes it. Dates, systems, characters and native roll types
have their own filters. Names are saved separately for the player and character.

One active GM saves records. History survives normal chat deletion. A returning
GM catches up chat that is still present. If chat is deleted while no recorder
was online, those missing records cannot be recovered.

Public rolls only: blind/private rolls are omitted, along with hidden DCs and
outcomes. PF2e action identity distinguishes Grapple from a plain Athletics
check. Its reroll cards can contain only the kept result; complete linked
physical reroll history is unfinished. Other systems retain generic dice,
formula, total, date and player data when no action identity is available.

Theme: System default follows Foundry's application theme. Light and Dark
override only Roll Ledger on your device. An open report keeps its filters,
focus and scroll when the theme changes.

Install through the SpazzMods Installer, or use this manifest in Foundry:
https://github.com/Spazzletopia-Studios/Roll-Ledger/releases/latest/download/module.json

Supported native test lines: Foundry13.351/PF2e7.12.2 and D&D5e5.3.3;
Foundry14.368/PF2e8.5.0 and D&D5e6.0.2. Other systems use the generic roll fields;
their engine-specific action details have not been tested.
